# День за днем — тижневий записник

**Головне вікно «Бетонарка» — паперовий тижневий планер** (понеділок–п'ятниця великими колонками 06:00–21:00, субота/неділя праворуч, MĚSÍC, ÚKOLY, VELMI DŮLEŽITÉ, NEZAPOMEŇ).

## Як запустити

**Windows:** розпакуйте архів у постійну папку й двічі натисніть `start-windows.bat`. Потрібен Python 3. У браузері відкриється `http://127.0.0.1:8765/`.

**Linux/macOS:** `python3 launcher.py`, далі відкрийте ту саму адресу.

**Швидкий огляд:** відкрийте `index.html` у браузері. Для постійного використання запускайте через `launcher.py`: у деяких браузерах `file://` має нестале зберігання.

## Головне вікно

- Після запуску автоматично відкривається **«План бетонарки»**.
- Кнопки `‹` / `›` перемикають тижні. **Поточний тиждень** повертає до сьогоднішнього.
- Щоб **додати замовлення на конкретну годину**, натисніть на порожнє місце клітинки або піктограму `▣`. Відкриється **модальне вікно**. Усі поля спочатку порожні, окрім обраної дати й часу. Для **звичайної справи** натисніть маленьке `+` праворуч — відкриється повна форма з назвою, приміткою, датою і часом.
- Щоб змінити **колір**, опис, час, пріоритет, дату, відкрити або видалити справу, натисніть на її назву. Кольори: зелений, помаранчевий, рожевий, жовтий.
- Позначайте виконання чекбоксом біля справи. Справи без часу з'являються внизу дня.
- Поле **NEZAPOMEŇ** для кожного дня, **ÚKOLY** (список 14 справ на тиждень) і **VELMI DŮLEŽITÉ** (важливі нотатки) редагуються прямо на головному екрані.
- **Друк / PDF:** відкриває стандартне вікно браузера. Для читабельного аркуша рекомендується A3 landscape. PDF можна створити через «Друк → Зберегти як PDF».
- У **«Мій день»** залишились повні завдання, окремі нотатки та цілі тижня. У **«Записник»** — нотатки з пошуком. Натисніть **«＋ Нове завдання»**, щоб додати справу на потрібну дату, зокрема без часу.

## Зберігання

Дані автоматично зберігаються в `localStorage` браузера на адресі `http://127.0.0.1:8765/`. Стара версія використовувала **той самий ключ**: при відкритті програми за тією ж адресою і в тому самому профілі браузера попередні справи та нотатки збережуться. Нові поля додаються автоматично. **Важливо:** не очищуйте дані браузера, не змінюйте адресу/порт без створення резервної копії. Старі резервні копії JSON також сумісні.

У меню ліворуч натисніть **«↓ Зберегти копію»** і тримайте файл JSON окремо від програми. **«↑ Відновити копію»** замінює всі поточні дані після підтвердження. Автоматичної хмарної синхронізації поки немає.

## Бетонарка — модуль замовлень бетону (нова версія)

Тижневий планер тепер є **головним вікном бетонарки**. Натисніть **«＋ Замовлення бетону»** зверху або маленький символ **▣** у рядку потрібного дня/години. У картці можна вказати:

- **Zákazník** — замовника (фірма/ім’я), дата й час поставки.
- **Beton** — сорт/рецептуру бетону: можна вибрати C20/25, C25/30, CP20, CP25 тощо, **або вписати будь-яку свою**. Окремо доступна фракція.
- **Množství** — кількість у м³ (допускаються дробові значення, напр. `8.5`).
- **Čerpadlo** — без насоса, малий насос або великий насос. Для великого треба вказати довжину стріли **від 36 м** (наприклад, 36, 42, 52). Це правило поділу типів реалізовано за завданням користувача, не як універсальний технічний стандарт.
- **Adresa stavby** — адресу доставки, **Kontaktní osoba**, телефон і необов’язковий e-mail.
- Статус (нове / підтверджено / в дорозі / виконано / скасовано) й операторську примітку.

Замовлення з’являються у вибраній годині тижневого аркуша. Натискання на мінікартку відкриває **режим перегляду**: усі збережені поля заповнені й заблоковані. Кнопка **«✎ Редагувати»** розблоковує їх; зміни застосовуються тільки після натискання **«Зберегти зміни»**. Після збереження вікно автоматично повертається до захищеного режиму перегляду.

**Швидке перенесення:** у режимі перегляду є окремий блок із полями нової дати й часу. Для швидкої зміни натисніть **−1 день / +1 день / −1 год / +1 год / −30 хв / +30 хв** або виберіть термін вручну; **«↪ Перенести»** оновлює тільки дату і час, а всі інші дані замовлення лишає незмінними. Якщо після перенесення змінюється тиждень, планер показує тиждень нової дати. На панелі тижня видно кількість замовлень та сумарний об’єм (без скасованих). Розділ **«Замовлення»** містить увесь список із пошуком за клієнтом, телефоном, бетоном, адресою та приміткою; телефони у списку натискаються. Розділ **«Мій день»** показує всі поставки на вибрану дату.

**Збереження та оновлення:** Усі записи зберігаються локально в тому самому сховищі `den-za-dnem-planner-v1` на адресі `http://127.0.0.1:8765/`. Існуючі завдання, нотатки й записи тижня не змінюються. JSON-копії зі старої версії відкриваються, а нові резервні копії містять і замовлення бетону. Для перенесення програми на інший ПК створіть резервну копію через **«Зберегти копію»** та відновіть її на другому комп’ютері. **Важливо:** телефони й адреси — персональні/комерційні дані, вони зберігаються у браузері та в JSON без шифрування. Бережіть профіль браузера й резервні копії; ця локальна версія не призначена для спільного доступу через публічний інтернет.


## Зміни версії 3

- Головна тижнева таблиця, кольори, заголовки й бічна панель залишилися на своїх місцях.
- Нове замовлення має порожню форму (дата й час проставляються з обраного рядка).
- Збережене замовлення відкривається лише для читання, з окремою кнопкою **«Редагувати»**.
- Редагування й перенесення терміну — дві різні дії, щоб уникнути випадкових змін у контактах чи рецептурі.
- Звичайні справи із кнопки `+` також додаються через повноцінне модальне вікно, а не через рядковий ввід.
- Зберігається стара структура даних і той самий ключ браузерного сховища.

## Виправлення v3.1 — без дублювання дати й часу

- У режимі **перегляду** дата та час показуються лише у верхньому блоці **«Швидко перенести»**. Повторні поля «Дата поставки» / «Час поставки» всередині заблокованої картки прибрані.
- Під час **створення** або після натискання **«Редагувати»** залишаються звичайні поля дати та часу в основній формі; верхній блок швидкого перенесення в цей момент не показується.
- Кнопки швидкого перенесення та збереження замовлень працюють як раніше. Головний тижневий екран, дані та ключ localStorage не змінені.
