# Betonarka public demo

Ця гілка містить тільки статичну демонстраційну версію застосунку. Усі початкові замовлення вигадані. Користувацькі зміни зберігаються лише в sessionStorage конкретної вкладки. **Не вводьте реальні дані клієнтів.**

Основний репозиторій і виробничі дані залишаються приватними. GitHub Pages має публічний доступ до опублікованих файлів.
